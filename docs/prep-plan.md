# Подготовка к ДЭ 15.01.31 — помесячный план по компетенциям

> **Рабочая версия, принята владельцем 16.11.2026.** Квест пройден, ДЭ — конец мая.
> Ось плана — **компетенции из КИМ 15.01.31-1-2027** (том 1), не часы: каждый месяц
> мы заранее знаем, какие умения отрабатываем и чем сверяем результат.
> Часы практики по расписанию не нормируем — сколько реально получается, столько и отрабатываем.
> Источники: КИМ (описания заданий 1–4), методички для ТЭ, стенд УЛС ШПН КИПиА,
> метод. рекомендации по оценке. Выполняем по задачам `plan.json` (de-2026-11 … de-2027-05).

## Структура ДЭ — 4 задания (справка из КИМ)

| № | Задание | Время по КИМ* |
|---|---|---|
| 1 | Поиск неисправностей в системах автоматики (стенд ШПН) | 30 мин |
| 2 | Механический монтаж систем автоматики (по монтажной схеме) | 1 ч |
| 3 | Коммутация систем автоматики (по ПЭС и кабельному листу) | 1 ч 30 мин |

\* время — ориентир регламента экзамена, в плане подготовки не нормируем.

## Помесячная разбивка по компетенциям

### Ноябрь 2026 — задание 1: поиск неисправностей (текущий месяц)

**Компетенции:**
- подготовить измерительное оборудование, проверить пригодность приборов к использованию (ПК);
- работать в двух режимах безопасно: при поданном питании и при отключённом (ОТиТБ);
- выполнять визуальный поиск неисправности;
- выполнять поиск прибором (прозвонка, замеры);
- отметить найденную неисправность на ПЭС кругом с номером;
- различать виды неисправностей по КИМ: обрыв; «залипший» нормально-открытый контакт (нет смены режима).

**На стенде:** ШПН, 5 переключателей неисправностей S1–S5 (вносит техэксперт/мастер),
одновременно включена только одна неисправность, при переключении — полное обесточивание шкафа.
Запуск установки без неисправностей запрещён. Не бывает по КИМ: КЗ на линии питания, неисправное оборудование.

**Как отрабатываем:** чтение ПЭС стенда → методика «визуально → прибор → отметка на схеме»
на пробных внесённых неисправностях → каждый прогон с новой случайной неисправностью
(по таблице случайного распределения из КИМ).

**Освоил, если:** студент сам локализует неисправность и корректно отмечает её на схеме;
сами обесточивает/подаёт питание по правилам; не путает обрыв и залипший контакт.

**Контроль (30.11):** пробное З1 без времени, разбор ошибок локализации.

### Декабрь 2026 — закрепление З1 + старт задания 2

**Компетенции (новые — З2):**
- читать монтажную схему;
- механический монтаж на стене: шкаф (с напарником/мастером), кабеленесущие системы, электродвигатель, кнопочные посты;
- установка оборудования: модульное на DIN-рейку, лампы, кнопки, переключатели;
- маркировка оборудования на стене и в шкафу.

**Как отрабатываем:** до уверенности доводим З1 (методика та же, прогресс по числу ошибок);
параллельно знакомим с монтажной схемой, разметкой, DIN-рейками, набором оборудования.

**Освоил, если:** З1 выполняет устойчиво и без подсказок; умеет разметить место,
поставить модульное оборудование на рейку, промаркировать.

**Контроль:** срез З1 (когда готовы — можно уже с ориентиром времени 30 мин);
мини-проверка установки и маркировки.

### Январь 2027 — завершение З2 + начало З3

**Компетенции (закрепление З2 + новые З3):**
- чтение структурной схемы алгоритма; проверка работы собранной функции;
- разделка кабеля (отрезать → зачистить);
- оконцевание проводов: НШВИ, НКИ;
- групповые операции вместо хаотичных: за один приём «отрезал → зачистил → оконцевал → подключил»;
- укладка и жгутование, работа в кабель-канале и проволочном лотке.

**Как отрабатываем:** З2 по монтажной схеме до полной сборки с проверкой функции;
З3 начинаем с ручных навыков: разделка, оконцевание, первые заготовки, укладка.

**Освоил, если:** собрал по монтажной схеме и функция работает; оконцевание аккуратное,
изоляция не повреждена; операции идут группами, а не хаотично.

**Контроль:** срез З2; проверка качества заготовок (визуально по образцу).

### Февраль 2027 — задание 3 полностью

**Компетенции (З3):**
- читать принципиальную электрическую схему и кабельный журнал (лист);
- коммутация модульного оборудования в шкафу;
- коммутация ламп, кнопок, постов, электродвигателя — подключение кабелей с двух сторон;
- разделение цепей в лотке/канале: силовые, цепи управления, цепи измерения, заземление, интерфейсы;
- маркировка кабелей.

**Как отрабатываем:** полная коммутация стенда по ПЭС + кабельному журналу,
несколько полных прогонов; разбор по чек-листу типовых ошибок из методички:
повреждение изоляции, хаотичные операции, неверное чтение схем.

**Освоил, если:** щит коммутируется полностью и функция работает;
цепи разделены, кабели промаркированы, изоляция цела.

**Контроль:** срез З3 + разбор по чек-листу ошибок.

### Март 2027 — задание 4: программирование

**Компетенции (З4):**
- работать в ПО для ПЛР/ПЛК (языки стандарта МЭК 61131-3);
- определить и промаркировать входы/выходы (таблица DI/DO);
- выполнять функции алгоритма последовательно и ПОЛНОСТЬЮ (не перескакивать);
- аварийный стоп S1 (HL3 — 5 Гц), удержание SB1 5 с (HL3 — 2/4 Гц), реверс K1/K2;
- загрузить программу в ПЛР/ПЛК и провести апробацию (наладку).

**Как отрабатываем:** по алгоритму работы электроустановки (адаптированному под наше ПЛР —
см. «Что уточнить»); каждую функцию доводим до полной работы, затем следующая;
в конце — прогон с изменёнными уставками (вариативность).

**Освоил, если:** программа собрана, загружена, все функции алгоритма выполняются полностью,
аварийный стоп и реверс работают.

**Контроль:** срез З4 с изменёнными уставками.

### Апрель 2027 — интеграция: полные репетиции

**Компетенции:** все 4 задания подряд как единая работа.

**Как отрабатываем:** 2 полные репетиции по регламенту ДЭ: З1 → З2 → З3 → З4,
оценки сразу после каждого задания, студент не присутствует при оценке.
Вариативность: З2 — изменение схемы расположения оборудования, З4 — изменение временных уставок.

**Результат:** таблица слабых мест на каждого студента.

**Контроль:** 2 репетиции + таблица слабых мест.

### Май 2027 — точечная отработка и экзамен

**Компетенции:** доработка слабых мест по итогам апреля (индивидуально).

**Как отрабатываем:** точечные мини-прогоны по слабым компетенциям;
1–2 финальных прогона в режиме ДЭ; подготовительный день: внесение неисправностей в ШПН,
монтажный шкаф, расходники (по методичке для ТЭ).

**Контроль:** ДЭ — конец мая.

## Сквозные компетенции (каждый месяц, в фоне)

- ОТиТБ и СИЗ: проверка/одевание до начала любой работы — оценивается в каждом задании.
- Техническая документация: отметки на схемах, маркировка, ведомости.
- Выполнение задания полностью: функцию доводим до конца, потом переходим к следующей (типовая ошибка ДЭ — неполная отработка).
- Только порученная по заданию работа; не включать в работу то, что не указано (правило из КИМ).
