# demoexam-kip

Материалы демонстрационного экзамена по профессии **15.01.31 «Мастер
контрольно-измерительных приборов и автоматики»** (КИМ 15.01.31-1-2027,
комплект № 6281).

Источник комплекта — [Банк оценочных материалов ИРПО](https://bom.firpo.ru/Public/6281).

## Состав

| Файл или папка | Что внутри |
|---|---|
| `КИМ 15.01.31-1-2027 Том 1.pdf` | спецификация: задания, баллы, оборудование, охрана труда |
| `Метод_рекомендации_СПО_15.01.31-1-2027.pdf` | рекомендации для представителей СПО |
| `Метод_рекомендации_Выпуск_15.01.31-1-2027.pdf` | рекомендации для обучающихся |
| `Прил_ОЗ_КИМ_15.01.31-1-2027/` | приложения по заданиям 1–4 для БУ и ПА |
| `Алгоритм работы установки.docx` | описание алгоритма электроустановки |
| `Доклад_Алгоритм_работы.docx` | текст доклада о стенде: таблицы переведены в текст |
| `_служебное/` | индекс папки, извлечённые тексты PDF и DOCX, скрипты извлечения |

## Задания

1. Поиск неисправностей на шкафу ШПН — 30 минут, 25 баллов.
2. Механический монтаж — 1 час.
3. Коммутация — 1 час 30 минут.
4. Программирование ПЛР — 30 минут, 21 балл.

Монтаж и коммутация вместе дают 29 баллов; инвариантная часть — 75 баллов.

## Чего в репозитории нет

- `*.rar` и `Прил_ОЗ_КИМ_15.01.31-1-2027.zip` — архивы, их содержимое распаковано рядом;
- `*.bak` — резервные копии чертежей;
- `AUD-*.m4a`, `AUD-*.txt` — аудиозапись и расшифровка репетиции доклада.

Исключения перечислены в `.gitignore`.
