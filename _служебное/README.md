## Что в _служебное

- `текст_документов\*.txt` — извлечённый текст всех PDF и DOCX комплекта
  (для быстрого поиска: Ctrl+F / grep). Основные:
  - `КИМ 15.01.31-1-2027 Том 1.txt` — полный текст спецификации (~35 стр.).
    Важно: таблицы в тексте «рассыпаны» (столбцы идут друг за другом).
  - `Метод_рекомендации_СПО…`, `Метод_рекомендации_Выпуск…` — тексты методичек.
  - `ШПН ПЭС.txt`, `ШПН ПЭС Эталон.txt`, `ШПН МС.txt` — текст схемы шкафа поиска
    неисправностей (обозначения элементов; графические детали/номера неисправностей
    только в PDF).
  - `Монтажная схема.txt`, `Принципиальная электрическая схема.txt` — схемы заданий 2/3.
  - `docx_…txt` — тексты документов Word из приложений.
- `скрипты\extract_pdf.py`, `скрипты\extract_docx.py` — повторное извлечение текста
  (Python 3: `py -m pip install pdfminer.six`). Пути внутри скрипта поправить при изменении.
- `обновление_документов.ps1` — проверка/загрузка документов с bom.firpo.ru заново
  (если комплект обновили). Файлы — прямые ссылки `/file/public/<id>/<имя>`.
- `Конспект_ДЭ_15.01.31.md` — краткое описание экзамена (структура, баллы, задания).
- `README.md` — этот файл.

## API источника (для обновления)

- `https://bom.firpo.ru/api/EvaluationKit/GetPublicDocuments/6281` — JSON со списком
  всех документов комплекта (внутри `documentAttempts[].publicDownloadLink`).
- Прямые ссылки файлов: `https://bom.firpo.ru/file/public/<id>/<имя файла>`
  (id: 137245 = Прил_ОЗ *.zip, 168464 = Метод_рек…СПО, 168466 = Метод_рек…Выпуск,
  177978 = КИМ Том 1).

## Известные ограничения текста

- Схемы и PDF КИМ содержат графику (чертежи, номерованные неисправности на эталоне,
  картинки плана застройки) — текстовые файлы их не передают, смотреть оригиналы.
- RAR-исходники остаются рядом с распакованными папками (можно удалить, содержимое извлечено).
